# WPS Excel 翻译插件

> 在 WPS Excel 里**选中单元格**就翻译，多语言、多模型支持，外贸/翻译/数据分析人员的效率工具。

![点一下单元格 · 自动翻译](/images/projects/wps-translate.png)

在表格里点一下单元格，译文直接出在翻译结果面板，支持 **10 种语言互译**，多模型通用、永久买断、一码一机。

## 痛点

- 处理英文/外文 Excel 时，**一个一个查词**效率极低
- 在线翻译工具要"复制 → 切换窗口 → 粘贴 → 翻译 → 复制 → 切回"，**6 步操作打断思路**
- 表格内容多的时候，**上下文看不懂**，整段翻译更合理

## 解决方案

**选中即译**——在 WPS Excel 里**选中任意区域**，点一下按钮，**原文旁边自动出译文**。

核心特性：
- ✅ **选中即译**：支持单元格、区域、整列
- ✅ **多语言**：中英日韩 法德西俄葡阿等 10+ 语种
- ✅ **多模型**：智谱 / DeepSeek / 通义 / Kimi / OpenAI 可选
- ✅ **保持格式**：译文和原文保持同列 / 同行 / 新建 Sheet 三种模式
- ✅ **离线友好**：配置本地缓存，重复内容不重复扣费
- ✅ **术语库**：自定义专业术语翻译规则

## 三步开始使用

![三步开始使用](/images/projects/wps-translate-demo.png)

1. **安装插件**：下载安装包，打开 `publish.html` 一键安装，全程无需代码
2. **输入激活码**：打开翻译面板，填入购买的激活码
3. **配置使用**：填入自己的 AI Key，点选单元格自动翻译

## 技术栈

- **WPS 加载项**（基于 wpsjs）

- **翻译 API**：可配置（智谱 / DeepSeek / 通义 / Kimi / OpenAI）
- **存储**：wps.storage（用户配置持久化）
